# fof_vol_ct 

Root schema for the FISH Omics Format for Chromatin Tracing - Volumetric modality (FOF-vol-CT). Imports all twelve FOF-bas-CT table schemas plus the three FOF-vol-CT-specific table schemas. In FOF-vol-CT, the SM Localization Data table and SM Localization Quality table are mandatory; the Spot/Trace Data table is optional post-processing output.

URI: https://w3id.org/fof-ct/vol
