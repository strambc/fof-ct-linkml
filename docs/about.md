# About fof-ct

The FISH Omics Format for Chromatin Tracing (FOF-CT) for both Ball-and-Stick (FOF-bas-CT) and Volumetric (FOF-vol-CT) modalities was developed initially as part of the NIH-funded 4D Nucleome Project (https://www.4dnucleome.org/).

For more details please refer to the following:

1. [ReadTheDocs](https://fish-omics-format.readthedocs.io/en/latest/) documentation.

2. ArXiv.org preprint:

    Navelkar R, Cosolo A, Bintu B, Cheng Y, Gardeux V, Gutnik S, et al. FAIR sharing of chromatin tracing datasets using the newly developed 4DN FISH omics format - preprint [Internet]. arXiv [q-bio.OT]. 2025. Available from: http://dx.doi.org/10.48550/ARXIV.2508.13255
